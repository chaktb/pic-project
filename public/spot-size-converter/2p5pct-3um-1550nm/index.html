왜 단순하지 않은가

  • 모드 크기 차이: 2.5% Δ 3 µm 코어는 D4σ 3.9 µm 모드만 가두므로 SMF-28(10.4 µm)과 직접 맞대면 3.32 dB가 손실됩니다.
  • 두께 고정의 한계: 마스크로는 폭과 z 방향 duty만 바꿀 수 있습니다. 실효매질(duty 평균) 모델에서 손실이 최소인 facet은 폭 7–8 µm / duty 0.18 인데, 이때 모드는 11 × 9.5 µm 타원형이 되어 하한이 ≈ 0.166 dB입니다.
  • 세그먼트 산란: 2.5% 고대비에서는 갭 하나하나가 강한 산란체입니다. 실제 tooth/gap을 넣은 3D BPM으로 보면 실효매질 최적점(pitch 2.8 µm, duty 0.18)에 +0.5 dB의 방사 손실이 더해집니다. pitch를 줄이면 산란이 줄지만, tooth ≥ 0.5 µm 제약 때문에 facet duty의 하한(0.5/P)이 올라갑니다.
  • 즉 세그먼트 방사와 facet 모드 정합이 DRC를 통해 서로 묶여 있어서, 실효매질 모델이 아니라 실제 형상을 직접 평가하는 최적화가 필요했습니다.

해석 방법

η = |∫ Eout · ESMF* dA|² / ∫|ESMF|² dA  (입력 = 단위 파워 칩 고유모드)   →   Loss = −10·log₁₀ η
  • 모드 해석: 스칼라 유한차분 고유모드 solver (5-point Laplacian, sub-pixel 면적평균 굴절률).
  • 3D BPM: 스칼라 paraxial Crank–Nicolson, Peaceman–Rachford ADI, numba 병렬 Thomas 해법, 이차 흡수경계. 모드 solver와 동일한 이산 연산자를 써서 고유모드가 그대로 전파됩니다 — 500 µm 자기전파 overlap 0.99999999 (기존 페이지에서 언급한 “mode-beating artefact” 없음).
  • 손실 정의: facet에서의 출력장과 SMF Gaussian의 overlap이므로 테이퍼 방사 손실 + facet 부정합이 모두 포함됩니다. facet Fresnel 반사(굴절률 정합 가정)는 제외.
  • 수렴: 세그먼트 BPM은 고각 방사 성분 때문에 격자에 민감합니다 (pitch 2.8 µm 케이스: dx 0.35 → 0.34 dB, 0.18 → 0.57, 0.12 → 0.73, 0.09 → 0.70 dB). 최종 검증은 수렴 영역인 dx = 0.10 µm, dz ≤ 0.2 µm에서 수행했습니다.
  • Bragg 반사 회피: BPM은 단방향이라 역방향 Bragg 반사를 볼 수 없으므로, GA에서 2·P·neff/λ가 정수에서 0.08 이상 떨어지도록 제약했습니다. 최종 pitch 2.017 µm → 3.76–3.80 (정수 4와 0.2 이상 이격).

대안: solid inverse taper

갭이 없는 단순 폭 테이퍼(3 µm → 0.55 µm tip, 2 mm, √ 형상)도 같은 BPM으로 0.300 dB가 나와 segmented 설계와 거의 같습니다. tip 0.50 / 0.60 / 0.65 µm에서는 0.33 / 0.32 / 0.40 dB. 0.5 µm 갭 패턴이 부담스러운 공정이라면 고려할 만해서 GDS에 SSC_ALT_INV_TAPER 셀로 함께 넣었습니다 (길이가 2배 이상이고 tip 폭이 DRC 한계에 가깝다는 점은 감안).

한계와 주의

  • 스칼라 해석입니다 (TE/TM 구분 없음). 2.5% Δ에서 편광 의존성은 작지만 0.0x dB 수준의 차이는 있을 수 있습니다.
  • paraxial BPM은 세그먼트에서 고각으로 나가는 방사를 근사적으로만 다룹니다 — 2D FDTD 보정 결과 BPM이 약간 낙관적이어서 0.30–0.32 dB를 현실적 추정치로 봅니다.
  • 역방향 반사(Bragg, facet Fresnel)는 BPM에 포함되지 않습니다. Bragg는 pitch 선택으로 회피했고, facet은 굴절률 정합(접착제/젤)을 가정했습니다.
  • SMF-28은 MFD 10.4 µm Gaussian으로 근사했습니다.
