Why a spot size converter

  • The SMF-28 mode-field diameter is ~10.4 µm at 1550 nm, while a 2.5% Δ, 3×3 µm silica core guides only a 3.9 µm (D4σ) mode — the bare butt-coupling loss is 3.32 dB.
  • The 3 µm core thickness is fixed by deposition, so the converter must be drawn in the mask plane only: segment width and duty lower the local effective index and let the mode swell in both x and y.
  • At 2.5% Δ every gap is a strong scatterer. A coarse fixed pitch (e.g. 2.8 µm) adds ~0.5 dB of segment radiation, so the pitch is kept as short as the 0.5 µm rule allows wherever the duty is mid-range — and the segments widen gradually so the facet mode is large without pushing the duty to the rule limit too early.
  • Target: SMF coupling loss ≤ 0.3 dB, minimum linewidth / gap ≥ 0.5 µm.

Structure & design variables

Chip waveguide 3 µm solid (20 µm lead) → segmented section whose segments widen from 3 µm toward the SMF facet while their duty falls. Each period starts with a gap, then a tooth; the facet is cut at the end of the last tooth. The segment list is generated from a small gene vector:

Local pitch rule:   Pk = max( P_min , 0.5 µm / (1 − d) , 0.5 µm / d )  → nudged out of the Bragg bands m·λ / (2 neff), m = 2…6 (±0.03 µm guard)

So the gap is pinned at 0.5 µm near the chip (high duty), the pitch drops to P_min = 1.21 µm through the mid-duty region where scattering would be strongest, and the tooth is pinned at 0.5 µm near the facet (low duty). Every tooth and gap is ≥ 0.5 µm by construction (1 nm grid, rounded up). The BPM is one-way, so contra-directional Bragg reflection is screened analytically by the band rule.

Optimization workflow (GA ⇄ 3D BPM)

  • ① gene → structure: the 7-gene vector builds the tooth list (z₀, z₁, w₀, w₁) with the local minimum-pitch rule — the same list that is written to the GDS.
  • ② 3D BPM run: launch the 3×3 µm chip eigenmode and propagate through every real tooth and gap (scalar, paraxial Crank–Nicolson ADI, dx = 0.12 µm, dz ≤ 0.25 µm, absorbing boundaries).
  • ③ fitness: Loss = −10·log10 |⟨E_SMF | E_out⟩|² [dB] at the facet — taper radiation and facet mismatch both included.
  • ④ select · cross · mutate: tournament selection + BLX-α crossover + Gaussian mutation, elitism 2, population 16.
  • ⑤ iterate: 14 generations (224 BPM runs), then the best candidate is re-verified on a finer grid (dx = 0.10 µm, dz ≤ 0.2 µm).
Objective: minimize   f(g) = −10·log₁₀ η(g),   η = |∫ Eout·ESMF* dA|² / ∫|ESMF|² dA   (input = unit-power chip mode) 
# ga_widen.py (excerpt)
def fitness(genes):
    des   = from_genes(genes)                      # WideningSSC: tooth list, DRC by construction
    psi,_ = bpm.run(chip_mode, segmented_slices(des, grid, plat, dz=0.25))
    return -10*log10(grid.overlap_raw(psi, smf))   # dB, smaller is better

# The mode solver and the BPM share the same 5-point Laplacian, so an eigenmode

Equations

SMF mode (Gaussian): E_SMF(r) = exp(−r²/w²),   w = MFD/2 = 5.2 µm
Overlap: η = |∫ E_a·E_b* dA|² / (∫|E_a|² dA · ∫|E_b|² dA),    Loss(dB) = −10·log₁₀(η)
Index from Δ: n_core = n_clad / √(1 − 2Δ),   Δ = (n_core² − n_clad²)/(2 n_core²);   n_clad = 1.44402 (Malitson), n_core = 1.48154  (the browser panel uses n_clad/(1 − Δ) — within 0.0005)
Paraxial BPM: ∂ψ/∂z = (i / 2β₀) [ ∂²/∂x² + ∂²/∂y² + k₀² n²(x,y,z) − β₀² ] ψ   (Peaceman–Rachford ADI, Crank–Nicolson)
