SSC (spot size converter)

Spot-size converter designs that expand a small silica-waveguide mode to match an SMF-28 fiber. Each entry below is a specific platform/geometry with its own GA + 3D-BPM result, source code, and downloadable GDS.

1301 nm · 2% Δ silica

2% 4.5 µm × 4.5 µm SSC

Segmented (digitized) inverse taper: chip waveguide 4.5 × 4.5 µm solid → 8.5 µm-wide low-duty SMF facet. Pitch / width / duty / segment count optimized by a genetic algorithm driving a Python split-step 3D BPM. Best coupling loss 0.246 dB (94.5%) at 1301 nm. Includes interactive estimator, result figures, full source code, and GDS downloads.
