Equations

κ = 2·κ_x²·γ_x·exp(−γ_x·gap) / [β·(κ_x²+γ_x²)·(1+γ_x·a)],  a = W/2
L_c = π/(2κ),  L_50 = π/(4κ)
P_cross(z) = sin²(κz),  P_through(z) = cos²(κz)
