Method

Mode field diameter (D4σ):  σ² = ∫r²·I dr / ∫I dr,  I = |E|²,  MFD = 4σ  (per transverse direction).
Coupling loss to SMF:  η = η_x·η_y,  η_dir = (∫G·F)² / (∫G²·∫F²),  Loss(dB) = −10·log₁₀ η.
G = SMF Gaussian (w = MFD_SMF/2); F = waveguide slab-mode profile (EIM, TE-TE). Cladding n from Sellmeier (Malitson 1965), core = clad / (1 − Δ/100).
