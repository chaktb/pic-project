Equations

SMF mode (Gaussian):  E_SMF(r) = exp(−r²/w_smf²),  w_smf = MFD/2
WG mode (separable EIM): E_WG(x,y) = X(x)·Y(y), each is the symmetric-slab fundamental TE.
Overlap factorizes: η = η_x · η_y,   η_dir = (∫ G·F dr)² / (∫G² dr · ∫F² dr)    Loss(dB) = −10·log₁₀(η)
